# Public cloud demo

This folder is prepared for Streamlit Community Cloud with Python 3.12 and `app.py` as its entry point. The cloud app runs while the owner's laptop is off. Free apps can sleep after 12 hours without traffic; viewers can wake them from the browser.

The source is published in a new, dedicated public demo repository. Deployment does not require Streamlit access to private GitHub repositories. Existing repositories and their settings are outside this deployment's scope.

Only generated app code, configuration, dependency lists and synthetic samples are published. Local environments, credentials, uploads, model caches and tunnel helpers are excluded. Management should use synthetic documents for this public POC.

All 9 tools and 29 strategies are retained, including plain-language explanation popups. Docling and semantic chunking download models on first use and require more resources than plain text splitters.

Deployment and hosted checks are pending. The resulting URL and verification results will be saved with the deployment record when completed.
